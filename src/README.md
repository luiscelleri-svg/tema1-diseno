## Descripción



Este repositorio contiene las actividades y avances desarrollados durante la asignatura Diseño de Software.



## Objetivo del proyecto



Aplicar principios de diseño orientado a objetos para desarrollar software robusto, mantenible, escalable y comprobable.



## Herramientas



- Java

- Maven

- Git

- GitHub

- JUnit



## Estructura



- `src/main/java`: código fuente.

- `src/test/java`: pruebas.

- `pom.xml`: configuración del proyecto Maven.



## Ejecución



Para compilar: `mvn clean compile`



Para ejecutar pruebas: `mvn test`
